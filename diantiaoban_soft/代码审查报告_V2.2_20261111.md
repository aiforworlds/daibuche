## 0. 结论摘要

功能逻辑是通的：换相搬进霍尔中断、超前角运行时可调、弱场滑行兜底、超前角 20ms 渐变这几层补丁都是有效的，方向也对。问题集中在三类：



1. **并发与安全壳**：`Motor_Set()` 的 6 次寄存器写不是原子的，会被抢占优先级 0 的霍尔中断撕开（P0-1）；运行期完全没有过流保护（P0-2）；掉线后动力保持 1.4\~2.1s（P0-3）。

2. **判据写错导致 "不该停时停"**：NTP 每个包都重写状态，单包时间戳跳变就整机断动力（P0-4）；自检的 NTC 判据把 "传感器开路" 读成 0℃，没接 NTC 或 5℃ 以下永远起不来（P1-1）。

3. **硬件没被驱动**：风扇休眠脚 PA15 从来没配置过，DRV8837C 一直睡眠，**风扇从来没通过电**（P1-3）。

共 23 条：P0 四条、P1 七条、P2 十二条。其中 **9 条已在&#x20;**`电调板_软件工程_V2.3`**&#x20;里修掉并编译通过**（详见第 5 节），其余按第 7 节排序处理。

## 1. P0：会烧硬件 / 骑行中失控

### P0-1 换相寄存器写入被霍尔中断撕开 ★已修



* 位置：`BLDC_Motor.c:171-245`（`Motor_Set`）、`Hall.c:115`、`BLDC_Motor.c:471/537/548`

* 现象：`Motor_Control()` 每轮主循环都走 `Motor_Direction()` → `Motor_Commutation()` → `Motor_Set()`，而 `Motor_Set` 是 6 次独立寄存器 / GPIO 写。霍尔 EXTI 抢占优先级为 0（`Hall.c:99`），必定能插入。

* 失败序列：主循环正在配 case 1（UH 高边 + UL/WL 使能），写第 4 行时被 ISR 打断；ISR 按新位置配 case 3（VH 高边 + UL/VL）；返回后主循环继续把 VL 拉低、WL 拉高 → 最终 VH 有占空比、UL 与 WL 同时使能 = **一相高边导通、两相低边并联到地**，一直保持到下一个霍尔沿（低速时数百 ms）。

* 定性：持续错相，不是瞬时毛刺。堵转电流与半桥直通都在这条路径上。

* 修法（已落地）：`Motor_Set` 首尾保存 / 恢复 PRIMASK。

* 彻底修法（未做，需评估）：主循环只更新 `Motor_Speed`/`Motor_comm_dir`，寄存器只允许霍尔 ISR 写；删掉主循环里每轮无意义的重复换相。**注意不能简单删**—— 静止起步时霍尔不动、没有 ISR，主循环这次调用正是 "起步那一脚"。

### P0-2 运行期没有任何过流保护 ★已修（阈值待标定）



* 位置：`AD.c:20`（`AD_Value[0]` = PA1 电流采样）、`main.c:282-289`（仅自检里判一次 `<5`）

* 现象：自检之后再没有任何地方读电流。堵转、错相、半桥直通全靠 MOSFET 自己扛。

* 修法（已落地）：TIM4 的 1ms tick 里逐拍判定，连续 10ms 超阈值即锁存并立即 `Motor_Set(0)`；主循环在锁存期间只做关断、不走滑行；电流恢复 2s 自动解除。

* **必须标定**：`OVERCURRENT_ADC_TRIP` 默认 3000（约 2.4V，满量程 73%），是 "宁可漏判" 的保守值。标定方法见第 6 节。

### P0-3 掉线后动力保持 1.4\~2.1s ★已修



* 位置：`APPTime.c:117-133`（看门狗 700ms 只升到 warning，再 700ms 才 error）、`main.c:433`（只有 `watchDog_status==error` 才置 `sys_status=error`）

* 现象：链路断后 `SetSpeedRC` 保留最后一杆油门，`Motor_Control(SetSpeedRC)` 照常输出。最坏 ≈ 2s，20km/h 约 8\~11m 无人控制。

* 修法（已落地）：`softWatchDog_loopCheck()` 在 **warning 阶段就把&#x20;**`SetSpeedRC=0`。遥控板心跳下行是 100ms / 包（`遥控板_软件工程_V2.1\APPTime.c:20` `HEARTBEAT_COUNT 100`），700ms 要连续丢 7 包才进 warning，正常骑行不会误触发；收油门后走 `Motor_Control(0)` 的弱场滑行，是平滑减速不是急刹。

### P0-4 时间戳单包否决，骑行中会突然掉动力 ★已修



* 位置：`main.c:800-810`（`RC_unpack` 对每个包按 `NTP_time - timestamp` 重写 `NTP_status`，容差 ±100ms）

* 现象：任何一次跳变（遥控器换电池重启、对端自己重新对时、两边晶振漂到 100ms —— ±20ppm 约 1.4h）都会 `NTP_status=error` → 主循环 `Motor_Control(0)` 断动力并进对时循环。表现是 "骑一阵子动力突然没了，灯闪一会又好了"。

* 修法（已落地）：连续 10 个包超差才判 error（约 1s），任何一个包回到容差内立即恢复 normal。

## 6. 上线前必须做的实机验证



1. **过流阈值标定（最重要）**：烧 V2.3 后，用串口调试（`Serial_Init` 115200，发 `'0'` 会打印 `ADC_AGND`）在三种状态下读 `AD_Value[0]`：静止 / 满载巡航 / 堵转。取 "额定电流 2 倍" 的码值，替换 `BLDC_Motor.c` 里的 `OVERCURRENT_ADC_TRIP`。**未标定前不要载人骑行**—— 阈值偏高只会漏判，但误判会导致骑行中断动力。

* 临时禁用（不改阈值也能跑）：把 `OVERCURRENT_ADC_TRIP` 设成 `4095` 即等于关闭。

1. **PA15 / 风扇**：V2.3 已拉高 nSLEEP。上电后量 PA15 应为 3.3V，且风扇在 "电机转动 5s 后" 应达到设定转速。若仍不转，问题在风扇本体供电或 PB15/IN2 电平逻辑，不在休眠脚。

2. **换相临界区**：示波器看任一相 PWM 与低边 SD 同时序，满油门、低速大扭矩工况各看一次，确认不再出现 "高边有占空比 + 两个低边同时导通"。同时确认电机声音没有变差（关中断窗口 <1µs，理论上无影响）。

3. **掉线行为**：骑行中直接关遥控器，应在约 0.7s 内平滑滑行减速；重新开机后应恢复油门，且不再出现 "必须重新对时"。

## 8. 增补（2026-11-11）：松手后轮子反向快速转 —— 根因与修复

### 8.1 这条不属于 V2.3 引入的回归

松手分支的代码在 V2.2 与 V2.3 里是**同一段**（V2.3 的 17 处改动没有碰过 `Motor_Control` 的 `inputSpeed == 0` 分支）。所以它是 V2.2 就存在的逻辑缺陷；如果是在烧了新固件之后才明显，那是同一处老代码在新程序里被触发，不是新版本改坏的。

### 8.2 根因：两条叠加

**（1）"弱场滑行" 实际是继续满力驱动**

`Motor_Control` 松手分支取 `calculate_min_slip_duty()` 作为滑行占空比：



```
Duty = (KE · ω + Delta_V) / V_bus ，  ω = 2v / D
```

代入 KE=0.130 V・s/rad、D=0.083 m、V\_bus≈40V（10S）：



| 松手时车速    | 5 km/h | 10 km/h | 20 km/h | 30 km/h | >32 km/h   |
| -------- | ------ | ------- | ------- | ------- | ---------- |
| 给出的滑行占空比 | 11%    | 22%     | 44%     | **65%** | **钳到 99%** |

也就是说 "松手" 等于 "以 65%\~99% 占空比继续驱动"，车速当然不降。这解释了 "推到一定程度才出现"—— 占空比随转速线性上升，低速时不明显。

**（2）反向转矩被 "自维持" 成反转**

转速降下来以后 `|Hall_rollSpeed| > 0.5` 的判据仍然成立（`HallSpeed_Timer` 100ms 计数 + 0.8 一阶滤波的双重滞后），占空比还挂着；而此刻的换相角是 `-Adv_Fwd_Now`，在 `ADV_STEP_MS`(20ms / 格) 的两步渐变期内还是 F4（相对对齐点超前 120°）。**小占空比 + 大超前角 + 接近零速**会给出反向转矩（与 `BLDC_Motor.c` 顶部记录的历史事故同型）。

转子被拖反之后，霍尔序列跟着反，但松手分支的换相方向是**写死的** `1 * DIRECTION * Motor_run_direction`，不跟随实际转向 —— 于是反向转矩继续存在 → 反向转速升高 → 霍尔继续反向 → 循环自我维持，就是 "向相反方向快速转"。

### 8.3 修复（`BLDC_Motor.c` / `Motor_Control` 松手分支）



| 改动         | 内容                                                                                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 去掉 BEMF 补偿 | 不再调 `calculate_min_slip_duty()`；占空比在 `COAST_RAMP_MS`(80ms) 内线性降到 0                                                                                                              |
| 到 0 后全关断   | `Motor_comm_dir = 0; Motor_Set(0);` —— 走 `default` 分支六路 MOS 全关 = **三相浮空自由滑行**。注意不能只把 CCR 清零还继续按 case 换相：那是 "一相低边 + 另一相低边同时导通"，等于两相短路制动，正是以前松手 "咯噔" 的来源（源码 `default` 分支注释也写明了这点） |
| 松手不切对齐角    | `Motor_weak_field = 0`，避免高速下换相角从 F4 突变到 F2 本身成为反向转矩源                                                                                                                            |
| 反向保险       | `Hall_Direction * cmd_dir < 0`（实际转向与指令方向相反）→ 立刻全关断、清 `Motor_comm_dir`，杜绝反向自维持                                                                                                   |
| 状态解耦       | 新增 `static uint8_t coast_ramping`，油门 / 刹车 / 零速分支均清零，避免 `isCoasting`（滤波快速系数标志）串扰导致 "下次松手不记起点、直接硬断"                                                                               |

编译：`0 Error(s), 4316 Warning(s)`，`Code=21136 RO-data=2296 RW-data=16 ZI-data=17584`（较上一版 +100B）。

### 8.4 行为变化（这是取舍，需要你确认）

现在 "松手"= **真断流 + 浮空滑行**：不再给力、不会反向，但**没有电制动**，台架上轮子会靠惯性转一会儿才停，路面上会滑行减速。

如果你要的是 "松手就明显减速停住"，那需要另外给一个受限的制动占空比（建议 ≤8%、限时 300ms、带斜降），这是产品取舍，我不替你定。

### 8.5 台架验证步骤（轮子悬空即可）



1. 推到 30%\~50% 松手：PWM 声应在 80ms 内消失，转速单调下降，**不出现反向**；

2. 推到满油松手：同上；

3. 松手后立刻轻推油门：应能正常起步（验证 `coast_ramping` 清零正确）；

4. 若仍然反向：说明问题在霍尔相序 /`DIRECTION` 配置而非本路径，需要同时打印 `Hall_Direction` 与 `cmd_dir` 的符号抓现场。

### 8.6 另一处同类过补偿（未改，等你决定）

`Motor_Control` 油门分支：



```
if (Speed >= calculate_min_slip_duty()) { Motor_Speed = Speed; ... }
else { Motor_Speed = calculate_min_slip_duty(); ... }   // 被"抬"到补偿值
```

高速时该阈值约 65%，所以 "油门只推到 50%" 会被抬到 65%，表现为 "油门松一点，车速不降"。建议改成两种情况都 `Motor_Speed = Speed`（弱场只决定换相角），另加 3% 起步下限防止低速推不动。要不要一起改，你说。

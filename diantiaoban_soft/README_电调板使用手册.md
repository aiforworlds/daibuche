# 电调板（ESC V260301）使用手册

> 板子：`SCH_电调板_V260301` / `BOM_电调板_V260301`
> MCU：STM32F103C8T6（LQFP48，128KB Flash）
> 本手册最后更新：2026-11-08

---

## 1. 一句话认识这块板

一块 **STM32F103C8T6 + 2.4G 遥控模块（JC24B）+ 三相无刷电机驱动（方波/六步换相）** 的电动滑板电机控制器（电调）。

```
XT30 电池(36V/10S) ──► TPS54560B ──► 12V ──► TPS5430 ──► 5V ──► AMS1117 ──► 3.3V
                           │                  │
                           └─► IR2104×3 自举 ──► Q1~Q6 三相全桥 ──► 无刷电机
```

**定位**：36V（10S，42V 满电）/ 10A 级三相无刷电调，霍尔传感器 + 方波六步换相，单电阻低边母线电流采样，带 2.4G 遥控模块串口、散热风扇驱动、NTC 测温。

## 3. 硬件要点（动手前必须知道的几件事）

### 3.1 必须用 36V 电池供电，Type-C/USB 供电不了它 ⚠

电调板的电源树是 `36V → 12V → 5V → 3.3V`，MCU 的 3.3V **完全由 36V 逐级降下来**。

- **要烧程序、要看灯亮、要跑程序，必须给 XT30 接上 10S 电池（或 36V 电源）。**
- 没接 36V 时，SWD 会报 `Unable to get core ID` / `No STM32 target found`。

> 烧写脚本里也写了：`1. 板子没有电 (36V 输入, 或从 U4 第1脚喂 5V)`。

### 3.2 烧写口 U4（4 针座）—— 引脚是明确的

| U4 脚 | 信号 | 接 ST-Link 哪个 |
|---|---|---|
| 1 | +3.3V | **不要接**（是 3.3V 输出，不是 5V）|
| 2 | PA13 = SWDIO | SWDIO |
| 3 | PA14 = SWCLK | SWCLK |
| 4 | GND | GND |

> ⚠ 与遥控板的 U6 不同，电调板 U4 的 2/3 脚 **SWDIO/SWCLK 是明确的**（网表确认：2=PA13=SWDIO，3=PA14=SWCLK），不用对调。

### 3.3 U4 没有 NRST ⚠

电调板烧写口**没有引出 NRST**，所以烧录命令**不能带 `mode=UR`**（用复位引脚会让 CLI 失败）。只能软件复位：

```
STM32_Programmer_CLI.exe -c port=SWD freq=1000 -e all -w ESC_V2.0.hex -v -rst
```

### 3.4 串口调试口 U7（3 针 1.25mm 座）

`1 = GND，2 = PA9(TX)，3 = PA10(RX)`，波特率 **115200**，无电源脚（板子自己靠 36V）。

V2.0 固件的调试串口指令（发单个字符）：

| 字符 | 作用 |
|---|---|
| `0` | 打印 Hall_Count / ADC_AGND / ADC_bat / ADC_NTC |
| `1` | 打印运行日志 |
| `2` | 清空日志 |
| `3` | 打印速度与方向 |
| `4` | 打印 Flash 存储区数据 |
| `5` | 保存数据到 Flash |
| `6` | 擦除 Flash 数据页 |
| `7` / `8` | 风扇最高速 / 最低速 |
| `A` / `B` | 进入 / 退出数据上报模式 |

### 3.5 BOOT0 / BOOT1 —— 有下拉，但 PB2 挂了 LED2 ⚠

- **BOOT0（pin44）**：网表显示接到跳线 + 测试点，原理图评审里写明有 **10k 下拉**，可切 3.3V/GND。烧录前确认 BOOT0 跳线在 GND 位。
- **PB2/BOOT1（pin20）**：网络名就叫 `PB2_BOOT1`，它**同时接了测试点 + LED2（红色）的负极**。

> 评审文档的 P2 级提醒：LED2 阳极经 510Ω 到 3.3V，会在 PB2/BOOT1 上拉出约 2V，复位时 BOOT1 被读成 1。
> **BOOT0=0（SWD 烧录）时不致命**；但若用串口 ISP（BOOT0=1）会落到 SRAM 启动。烧录用 SWD，不要动 PB2。

### 3.6 指示灯（全部低电平点亮）

| 位号 | 引脚 | 颜色 | 功能 |
|---|---|---|---|
| LED1 | +3.3V 直连 | 黄 | 纯硬件电源灯，常亮 |
| LED2 | PB2（BOOT1）| 红 | 自检未通过时亮，自检通过后灭 |
| LED3 | 共阳 510Ω 到 3.3V | 白 | 见 3.7 |
| LED4 | PA11 | 绿 | 绿灯 |
| LED5 | PA0 | 白 | PWM 呼吸灯（TIM2 输出，速度/心跳指示）|

> 还有一颗 LED 由 PC13 控制，是**错误指示灯（LED_ERROR）**，V2.0 固件里用它在 NTP 对时未完成 / 看门狗超时等场景闪烁或常亮。

### 3.7 遥控模块 U5（JC24B）接法

| U5 脚 | 信号 | 接 MCU |
|---|---|---|
| 1 | 3V3 | +3.3V |
| 2 | Rx | PB10（UART2 TX）|
| 3 | Tx | PB11（UART2 RX）|
| 4 | SET | PB5 |
| 5 | PD | PB4 |
| 6 | GND | GND |
| 7 | AUX | PB3 |

> ⚠ PB3/PB4/PB5 复位后默认是 JTAG 引脚（JTDO/NJTRST/JTDI），
> 固件里必须先把 SWJ_CFG 配成「只留 SWD」，这三个脚才能当 GPIO 用（固件已处理）。

## 4. 烧录

### 4.1 前置条件

1. **XT30 接好 10S 电池 / 36V 电源**（否则必失败）
2. ST-Link 的 SWDIO / SWCLK / GND 接到 U4 的 2 / 3 / 4（**1 脚空着**）
3. 关掉 Keil 等占用 SWD 的软件

### 4.2 一键脚本（推荐）

| 想烧什么 | 双击 |
|---|---|
| 电调板完整固件 V2.0 | `烧写工具\烧写_电调板V2.0.bat` |
| 只看运行状态（不烧） | `烧写工具\读取运行状态.bat` |

### 4.3 命令行

工具路径：

```
C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin\STM32_Programmer_CLI.exe
```

擦除 + 写入 + 校验 + 复位（一条搞定，**不带 mode=UR**）：

```
cd 电调板\固件
STM32_Programmer_CLI.exe -c port=SWD freq=1000 -e all -w ESC_V2.0.hex -v -rst
```

正常输出：

```
Device name : STM32F101/F102/F103 Medium-density
Flash size  : 128 KBytes
Mass erase successfully achieved
Download verified successfully
Software reset is performed
```

### 4.4 认板子，别烧错（读 UID）

```
STM32_Programmer_CLI.exe -c port=SWD freq=1000 -r32 0x1FFFF7E8 0x0C
```

| 板子 | UID 首字 | Flash | 固件栈顶 |
|---|---|---|---|
| **电调板**（这块）| `00600060` | 128KB | ESC_V2.0 = `0x20004500` |
| **遥控板** | `00600027` | 128KB | RC_V2.0 = `0x20004898` |

> 2026-11-08 实测：电调板 UID `00600060 59000002 56314C4D`；遥控板 UID `00600027 59000002 56314C4D`。
> 同一批次相邻芯片 UID 首字只差 1 位，烧录前务必读 UID 确认插的是哪块板。

### 4.5 烧完怎么确认真的在跑（不依赖屏幕/电机）

用 hotplug 模式（不复位芯片），连读寄存器：

```
STM32_Programmer_CLI.exe -c port=SWD freq=1000 mode=hotplug -r32 0x40000824 0x04
```

| 地址 | 寄存器 | 判读 |
|---|---|---|
| `0x40000824` | TIM4_CNT | 连读三次不同 = 1ms 时基定时器在跑 |
| `0x40010C0C` | GPIOB_ODR | bit2 = 0 → 红灯（LED2）亮 = 自检未过；1 = 自检已过 |
| `0x4001100C` | GPIOC_ODR | bit13 = 0 → 错误灯亮（NTP 未对时/看门狗超时）|
| `0x40021004` | RCC_CFGR | `0x001D840A` = 时钟已初始化 |

## 5. 遥控联调（对频验证）

### 5.1 协议版本必须配对 ⚠

电调板和遥控板用的是**同一套协议版本才兼容**：

| 协议版本 | 命令集 | 配对 |
|---|---|---|
| **V2.0（完整版）** | `CMD_HEARTBEAT_DOWNLINK 0x30` + `UPLINK 0x31` + 里程/运行时间 | 遥控板 RC_V2.0 ↔ 电调板 ESC_V2.0 |
| **V3.1（初始化版）** | 只有 `CMD_HEARTBEAT 0x30`（单向）| 遥控板 RC_V3.1 ↔ 电调板 遥控模块配置_V3.1 |

**混搭会出问题**：V3.1 遥控板发的 `0x30` 和 V2.0 电调板期望的 `0x30`（DOWNLINK）碰巧同号，握手能勉强走通，但心跳数据结构、速度映射不一致，实际控制会乱。**联调统一用 V2.0。**

### 5.2 对频成功判据（灯）

- 遥控板断电 → 电调板**错误灯开始闪烁**（NTP 进入 error，`LED_ERROR flicker`）
- 遥控板上电 → 两边各有一盏灯闪烁（握手期）
- **几秒后两边闪烁的灯同时熄灭** = NTP 对时成功、握手完成 ✓

（"同时熄灭"是唯一可靠的对频成功标志，源码路径：电调板 `NTP_status=normal` → `LED_Control(LED_ERROR, off)`。）

### 5.3 只验证对频、不接电机三根线

首次联调建议**只接霍尔线，不接电机三相线**，先确认对频握手成功，再逐步接电机做转动测试。

## 6. 已知问题（来自原理图评审，打板/下一版前需评估）

评审报告 `评审/原理图评审_20261026/` 里列出了 P0/P1/P2 问题，重点三条：

1. **P0-1 无硬件过流保护**：短路/直通时 FET 会在软件反应过来（100µs 级）之前炸掉，建议加 LM393 比较器硬件拉低 SD#。
2. **P0-2 驱动输入（IN/SD#）无下拉**：复位/烧录瞬间桥臂输出状态不确定，可能"电机自己转一下"，建议 6 路各加 10k 下拉。
3. **P0-3 TVS 钳位电压（77V）高于 MOSFET 耐压（60V）**：母线过压时 TVS 还没钳住 FET 先击穿。

> 完整清单（含 P1/P2 共 15 条）见评审 HTML，打板前务必过一遍。

```
【必须做】 XT30 接 36V 电池                       ← 没这步什么都别谈
【接线】   U4: 2=SWDIO 3=SWCLK 4=GND，1 脚(+3.3V) 空着
【烧写】   cd 固件 && STM32_Programmer_CLI -c port=SWD freq=1000 -e all -w ESC_V2.0.hex -v -rst
           （注意：不带 mode=UR，U4 没有 NRST）
【验证】   同上但加 mode=hotplug -r32 0x40000824 0x04，连读三次不同 = 在跑
【对频】   遥控板也烧 V2.0，两边灯闪烁→几秒后同时熄灭 = 对频成功
【协议】   电调板 V2.0 ↔ 遥控板 V2.0，别混搭 V3.1
```

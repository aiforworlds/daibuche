## 三、各替代明细

### 1. MOSFET BSC0702LS → AON6220（¥0.70）

| | 原 BSC0702LS | 替代 AON6220 |
|---|---|---|
| 耐压 | 60V | **100V（更安全）** |
| Rds(on)@10V | 2.7mΩ | 6.2mΩ（升高） |
| Id | 84A | 48A |
| 封装 | PG-TDSON-8(5×6) | DFN-8(5×6)，pin-to-pin |

⚠ 唯一风险：Rds 升高约 2.3 倍，满载发热增加，**务必温升实测**。耐压升到 100V 反而更稳（系统满电 42V）。

### 2. 半桥驱动 IR2104S → EG2104S（¥1.03）

- SOIC-8 pin-to-pin，600V 耐压，驱动电流更强（1A/1.5A vs 0.13A/0.27A）。
- **白赚**：IN/SD 内置 200K 下拉，解决评审 P0-2「驱动输入无下拉」隐患。

### 3. 36V→12V：TPS54560 → XL7005A（¥0.58）

- 5~80V 输入、0.4A 输出，12V 这路实际 <0.2A，够用。
- 引脚不同需改板；反馈基准 1.25V（原 0.8V）改分压；删 COMP 网络和 BOOT 电容；EN 低使能。
- 官方典型应用即「Ebike Controller Power Supply」，场景对口。

### 4. MCU STM32 → GD32F103C8T6（¥2.40）

- LQFP-48 pin-to-pin，108MHz（原 72MHz），需重编译固件 + 验证换相/串口。

### 5. 保持不动

- **TPS5430（¥1.48）**：与国产 XL1509（¥0.55~1.5）基本持平，换它不划算且需改板。
- **AMS1117-3.3**：LDO 最低价档，换了不省钱。
- **8MHz 晶振**：淘宝价 ¥4.67 反而高于立创 ¥1.50，建议晶振仍在立创买。
- 其余阻容/二极管/连接器：淘宝整包价已很低，无进一步替代空间。

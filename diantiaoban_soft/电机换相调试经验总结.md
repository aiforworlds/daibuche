## 二、核心换相逻辑（BLDC_Motor.c）

### 换相表 `Motor_Set()`（六步通电相）

| case | 通电相（上桥-下桥） |
|---|---|
| 1 | UH - WL |
| 2 | VH - WL |
| 3 | VH - UL |
| 4 | WH - UL |
| 5 | WH - VL |
| 6 | UH - VL |

### 方向判断 `Motor_Direction()`

```c
#define DIRECTION -1   // Hall.h

// main.c 油门分支调用：
Motor_Direction(1 * DIRECTION * Motor_run_direction);
// = 1 * (-1) * 1 = Motor_Direction(-1)
```

**关键：`Motor_run_direction` 从遥控器来，默认 = 1；`DIRECTION = -1`。**
所以**油门（前进）实际走的是 `case -1` 分支，不是 case 1！**

### 正确的换相偏移（已修复）

```c
case -1:  // 正转/油门实际路径
    MotorPosition = HallSensor.Position - 2;   // 超前 120°
    // 回绕：0 → 6，-1 → 5

case 1:   // 反转
    MotorPosition = HallSensor.Position + 1;
    // 回绕：7 → 1
```

## 三、霍尔状态与 Position 的关系

### 查表 `Hall_Position()`（Hall.c）

| ABC（A=PB13,B=PB14,C=PB12） | Position | 电角度 |
|---|---|---|
| 0 1 0 | 1 | 0~60° |
| 0 1 1 | 2 | 120° |
| 0 0 1 | 3 | 180° |
| 1 0 1 | 4 | 240° |
| 1 0 0 | 5 | 300° |
| 1 1 0 | 6 | 360° |

### 实测序列（本次电机，前进方向）

用手转电机一圈，ST-Link 采样得到稳定循环：

```
100 → 101 → 001 → 011 → 010 → 110 → 100 ...
```

对应 Position：**5 → 4 → 3 → 2 → 1 → 6（递减）**

**结论：本电机前进方向 Position 是递减的，所以超前 120° = `Position - 2`。**

## 四、决定性调试方法：ST-Link 读寄存器测线序

不需要 USB 转串口，直接用 ST-Link 读 GPIO 输入寄存器。

### 原理

霍尔三相信号接在 PB12/PB13/PB14，输入电平在 `GPIOB->IDR` 寄存器：

- 地址：`0x40010C08`
- bit12 = C（PB12），bit13 = A（PB13），bit14 = B（PB14）

### 方法一：OpenOCD 连续采样（推荐）

工具：`tools/openocd/bin/openocd.exe`，脚本已备好：`tools/openocd/hall_probe.tcl`

```bash
cd tools/openocd
./bin/openocd.exe -f interface/stlink.cfg -f target/stm32f1x.cfg -f hall_probe.tcl
```

脚本会 halt 内核、连续采样 IDR 约 45 秒，检测到电平变化就打印 `ABC=xxx`。
**运行期间手动匀速转电机一圈以上**，即可得到霍尔序列。

### 方法二：STM32CubeProgrammer 单次读取

```bash
STM32_Programmer_CLI.exe -c port=SWD freq=1000 mode=hotplug -r32 0x40010C08 0x01
```

返回 32 位值，手动解析 bit12/13/14。适合单次确认，不适合连续采样。

### 采样结果怎么用

1. 记录稳定循环的 6 个状态（忽略开头转动的过渡乱序）。
2. 对照查表，判断 Position 是**递增**还是**递减**。
3. 递增 → 正转超前 120° = `Position + 2`；递减 → `Position - 2`。

## 五、本次踩过的坑（重要！）

### 坑 1：改错了分支，白烧三次

油门实际走 `case -1`（因为 `DIRECTION=-1`），但一开始一直改 `case 1`，改了三次（-2/+2/-1）都没作用到实际运行路径。

**教训：改换相偏移前，必须先确认油门实际走的是 `Motor_Direction(1)` 还是 `Motor_Direction(-1)`。**

判定公式：`油门分支 = 1 * DIRECTION * Motor_run_direction`。
- `DIRECTION = -1`，`Motor_run_direction = 1` → 结果是 `-1` → 走 case -1。

### 坑 2：纸面推导方向符号不可靠

霍尔采样方向、查表方向、DIRECTION、Motor_run_direction 多层符号叠在一起，纯纸面推导"超前/滞后"极容易搞反。

**教训：用 ST-Link 实测霍尔序列，比任何纸面推导都靠谱。**

### 坑 3：症状判断

- **"憋一下冲一下"（能转但扭矩小）**：换相滞后（超前角不足），典型是偏移方向错 60°。
- **"锁死、扭一下啸叫"**：换相完全反向（滞后 120°）。
- **"平滑大扭矩"**：超前 120°，正确。

## 八、未来换电机操作清单

换新电机时，按以下步骤快速适配：

1. **接线**：三相 UVW、霍尔三信号线接好，先不上大电压。
2. **测线序**：跑 `hall_probe.tcl`，用手转一圈，记录霍尔序列。
3. **判断方向**：对照查表，确定 Position 递增还是递减。
4. **改偏移**：在**油门实际走的分支**（case -1）里，把偏移改成：
   - Position 递增 → `Position + 2`
   - Position 递减 → `Position - 2`
5. **回绕处理**：注意 `Position` 加减后越界（0/-1 或 7/8）的回绕。
6. **编译烧录**：-O1，确认体积不超 32KB。
7. **验证**：缓慢推油门，应平滑起步、大扭矩。
8. **若仍不对**：先确认电机转动方向（正转/反转），再决定是否要对调 Hall 两根线或三相中两根相线。

> 核心原则：**先实测霍尔序列定方向，再改对分支的偏移量，不要盲试。**

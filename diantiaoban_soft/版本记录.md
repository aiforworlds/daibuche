## 1. 为什么还要再改

用户台架结论：V2.5 **刹车确实在起作用，但力不够**（架空能瞬间停、落地减速感很弱）。

这是两相短路的物理上限：两相短路时只有两个绕组参与，相电流 ≈ 线电动势/(2R)，耗散功率 ≈ 1.5·e²/R。

**三相短路（三路下桥全通 = 零矢量）能让三个绕组都参与**：
- 每相电流 ≈ e_相/R；
- 耗散功率 = 3·e²/R；
- 制动转矩 = 功率/角速度。

⇒ 平均制动力 **约为两相短路的 2 倍**，而且与换相角、霍尔位置、母线电压、电池电流全都无关，也不存在“给电反转”的风险。

## 2. 改动

| # | 位置 | 改动 |
|---|---|---|
| 1 | `BLDC_Motor.c` 新增 `Motor_BrakeShort3()` | 三路 CCR=0 + 三路 SD# 全置位 = 三相下桥全通（三相短路），带 PRIMASK 临界区 |
| 2 | `Motor_Commutation()` 开头 | `if (Motor_brake3) { Motor_BrakeShort3(); return; }` —— 三相短路期间霍尔中断/main 都只维持这个状态，不再按六步换相写 SD# |
| 3 | `Motor_Control()` 刹车分支 | 刹车行程 ≥ `BRAKE3_PCT`(70%) → 三相短路；否则维持 V2.5 的两相短路 + 占空比比例（轻/中刹更线性） |
| 4 | `BrakeControl_Reset()` | 退出刹车时同时清 `Motor_brake3` |
| 5 | `BLDC_Motor.h` | 新增 `Motor_brake3` 与 `Motor_BrakeShort3()` 声明 |

**没有动**：油门、方向符号自学习、`Motor_Set` 临界区、电流限幅、松手滑行、NTP/看门狗。

## 3. 预期与代价

| 项 | 说明 |
|---|---|
| 制动力 | 约为 V2.5 的 **2 倍**（20 km/h 时按 R相 0.15~0.3Ω 估：轮上 180~370 N，0.23~0.47 g） |
| 电池 | **不抽电流**（短路回路不经过电池），保险丝零负担 |
| 反转风险 | **无**：短路只制动，不会驱动 |
| 代价 | 电机绕组发热翻倍：20 km/h 满刹时约 1~2 kW 全部耗在绕组/MOS 上，持续 2~3 s 可接受，**不能长时间拖刹** |
| 低速 | 制动力随转速线性下降（2~3 km/h 以下几乎没有），这是短路制动的固有特性；要低速也有力只能上反接制动（耗电、发热、保险丝风险，不建议） |

## 4. 台架验证

| # | 操作 | 预期 |
|---|---|---|
| 1 | 架空、中速、**下拉到底** | 比 V2.5 明显更“抓住”，停得更快，且**不反转** |
| 2 | 架空、下拉 50% | 轻柔减速（走两相短路路径），和 V2.5 类似 |
| 3 | 下拉 70% 前后对比 | 能感到一档“更硬”的制动（切三相短路的门槛） |
| 4 | 落地 20 km/h 满刹 | 应能明显减速停住；**建议先低速试**，确认不锁死打滑 |
| 5 | 连续 3~4 次满刹后摸电机 | 温热正常；烫手说明拖刹太久，改用中段刹车 |

## 5. 安全与回退

- 三相短路时三只下桥 FET 同时导通，相电流 ≈ e/R。若绕组电阻偏小（<0.1Ω），电流会很大 → 若发现刹车过于暴力/电机烫，把 `BRAKE3_PCT` 调高（如 85，只有拉到底才切）或改回 V2.5。
- 回退：`电调板/固件/ESC_V2.5_刹车短接法_20261124.hex`（两相短路）、`ESC_V2.4_方向符号与刹车_20261124.hex`（刹车会反转，仅存档）。

## 1. 改了什么

只改 `User/main.c` 的 OLED 第二行布局，**不动任何控制逻辑**：

| 元素 | 旧位置/文案 | 新位置/文案 |
|---|---|---|
| 温度标签 | `Temperture`（10 字符）x=0 → 0~59 | **`Temp`**（4 字符）x=0 → 0~23 |
| 温度值 | x=66，窄 2 位 66~89 / 宽 3 位 66~95 | x=**26**，窄 2 位 26~49 / 宽 3 位 26~55 |
| 电流标签 | `I:` x=96 | `I:` x=**70** → 70~81 |
| 电流值 | x=108，1 位整数（最大 9.9） | x=**82**，**2 位整数**（可显示 `10.0`、上限 19.9）→ 82~105 |
| 刷新区域 | x=96 宽 30 | x=70 宽 40 |

顺带把电流显示上限从 9.9 A 放宽到 19.9 A（2 位整数），并保留 1 位小数（0.1 A 分辨率）。

**r2（22:40）**：`Temp` 数值与 `I:` 之间原来只隔 2~8 px（温度到 3 位时几乎贴住），用户反馈“挨在一起不好看”。
把 `I:` 从 x=58 移到 **x=70**、电流值从 x=70 移到 **x=82**，间隙变成 15~21 px（2.5~3.5 个字符），
且数值为个位时还会自带一个前导空格，实际间距更松。其余不变。

## 3. 说明：电流数值本身没改

固件里电流换算仍是：

```
I = (ADC_AGND电压 − 上电零点) / (60 × 0.005Ω) = V/0.3
```

对应原理图：`R39 = 5mΩ`（AGND→GND）+ `LM358` 增益 `1 + R21/R22 = 1 + 10k/169Ω = 60.2`（网表核对）。
换算与硬件一致，若实测电流偏小，是采样链路或真实电流本身的问题，与本次界面调整无关；
可在 `电调板 .../User/AD.c` 的 `CURRENT_AMP_GAIN` 一个宏上做校准。
